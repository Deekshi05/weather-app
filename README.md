# Weather App

A simple and responsive weather application built using **HTML**, **CSS**, and **JavaScript** that displays current weather information for cities worldwide.

## Features

- Search weather by city name
- Displays temperature, weather condition, humidity, and wind speed
- Fetches live weather data using OpenWeatherMap API
- Displays weather icons based on current conditions

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeatherMap API
